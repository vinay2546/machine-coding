## How to practice

1. Open a problem README and clarify assumptions.
2. Design entities, interfaces, state transitions, and invariants.
3. Implement the core flow in Solution.java.
4. Add tests for success paths, edge cases, and failures.
5. Explain complexity, concurrency behavior, and design trade-offs.

## Project setup

Open the project as a Maven project in IntelliJ IDEA. Use Java 17. Add tests under src/test/java as you solve each problem.
